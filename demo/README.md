# Demo briefs

Synthetic assessment briefs for trying the document import. Every module, title and
date is invented; none of them comes from a real course.

| File                              | Shows                                                                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `demo-group-project-brief.pdf`    | A clear brief: one high-confidence deadline, weighting, deliverables, marking criteria, presentation date and group size |
| `demo-database-report-brief.docx` | Word headings, a bullet list of deliverables and a marking-criteria table; `11:59 PM` time                               |
| `demo-two-assessments.docx`       | Two assessments in one document (creates two deadlines)                                                                  |
| `demo-ambiguous-date.pdf`         | `03/04/2027`: both readings are offered and nothing is pre-selected                                                      |

To try them: open the extension's **Import** page, drop these files, review and confirm.
For demo deadlines without importing anything, use **Settings → Demo data**.

Regenerate with `npm run fixtures -- --demo`.
